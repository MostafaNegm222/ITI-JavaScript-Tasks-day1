# ITI JavaScript Tasks - Day 1

## 1. Description

Solutions for the ITI JavaScript day 1 tasks, practicing prompts, loops, functions and objects in the browser.

## 2. Technologies and Versions

- HTML5, vanilla JavaScript (no build step)

## 3. Requirements and Dependencies

- A modern web browser
- No packages to install

## 4. Installation and Run Steps

```bash
git clone https://github.com/MostafaNegm222/ITI-JavaScript-Tasks-day1.git
cd ITI-JavaScript-Tasks-day1
```

Open the task's HTML file in a browser; the scripts run with prompts and alerts.

## 5. Environment Variables

None required.

## 6. Usage and Main Features

- **Task 1 - Welcome alert and personalized greeting:** welcomes the user, asks for their name and favorite color (red, green or blue), and writes `Welcome [name]` in the chosen color.
- **Task 2 - Message in headings:** takes a message and displays it in every heading tag (`<h1>` to `<h6>`), generated with a loop (no hardcoded headings).
- **Task 3 - Sum of entered numbers:** keeps asking for numbers with a `do-while` loop, validates numeric input, and stops when the user enters `0` or the sum exceeds 100, then shows the total.
- Further tasks in the repo cover the same concepts with functions and objects.
